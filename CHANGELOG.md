### Added

- One-click installation of missing yt-dlp, FFmpeg, ffprobe and Deno runtime tools from their official project releases, with SHA-256 verification.
- Dedicated Windows AppUserModelID so the Media M8 window uses its own taskbar identity instead of being grouped as PowerShell.
- Initial Media M8 Windows GUI source.
- Native x64 Windows launcher source.
- Build and packaging scripts for development releases.

No public release has been published yet.
