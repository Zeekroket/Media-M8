# Security Policy

## Supported versions

Media M8 has not yet published a stable release. During early development, only the current code on the default branch is actively maintained.

## Reporting a vulnerability

Use GitHub private vulnerability reporting when it is available for this repository.

If private reporting is not available, open a public issue requesting a private contact channel without including vulnerability details.

Do not publish exploit details, credentials, private keys or other sensitive information in a public issue.
